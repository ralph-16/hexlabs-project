## Issues found while testing (not fixed yet)

1. **Titles containing "Set" are misread.** *"Logic and Set Theory Exercises due Friday, about 2 hours"* is treated as an edit command ("set …"), and SIKAD replies with a general "what changed?" question instead of adding the task. *"Set Theory worksheet due Friday"* gives "I couldn't find a task called 'Theory worksheet due Friday'". *"Logic Exercises due Friday"* works. For the safety test, the task was added with a title the parser accepts and then renamed. The fix belongs in `parser.js`, which needs approval under the project rules.
2. **The lab-report refusal uses coding steps.** For "…my Physics lab report…", the refusal works, but the steps were "Plan the solution / Implement / Test & debug", because "lab" is matched to the programming template. A writing-style breakdown would fit better.
